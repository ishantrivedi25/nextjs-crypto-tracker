# 📈 Crypto Market Dashboard

**A powerful crypto tracker providing real-time and historical market insights with an intuitive and user-friendly interface.**

---

## 🚀 Features

- 📊 **Real-Time Crypto Tracking** – Get live updates on cryptocurrency prices and trends.
- 🔍 **Detailed Coin Insights** – View market cap, volume, and price history with interactive charts.
- 🔄 **Coin Comparison** – Compare cryptocurrencies based on market cap, volume, and price trends.
- ⭐ **Watchlist Feature** – Keep track of your favorite coins for quick access.
- 📑 **Dashboard & Modules** – Includes Home, Compare, Watchlist, and Dashboard for easy navigation.
- 🔎 **Search & Pagination** – Quickly find and explore different cryptocurrencies.
- 🎨 **Modern & Intuitive UI** – Designed for an engaging and seamless user experience.
- 📈 **Historical Market Trends** – Gain valuable insights with 1-year price history charts.

---

## 🛠️ Tech Stack

- **Frontend:** React, Next.js, JavaScript, Material UI
- **Data & Charts:** Chart.js, CoinGecko API

---

## 📦 Installation & Setup

### 1️⃣ Clone the repository

```sh
git clone https://github.com/ishantrivedi25/nextjs-crypto-tracker.git
cd nextjs-crypto-tracker
```

### 2️⃣ Install dependencies

```sh
npm install
```

### 3️⃣ Start the project

```sh
npm run dev
```
